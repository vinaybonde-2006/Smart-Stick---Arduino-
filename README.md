
🚶‍♂️ Smart Stick Project using Arduino

This is my **Smart Stick Project**, designed to assist in obstacle detection using an **ultrasonic sensor**.  
When an object comes too close (within a few centimeters), a **buzzer** and **LED** activate to alert the user.  


🧠 Concept
The project uses an **HC-SR04 ultrasonic sensor** to measure distance.  
If the distance is less than or equal to 5 cm, the **buzzer** and **LED** turn ON — otherwise, they remain OFF.  
It’s a simple yet powerful demonstration of **distance sensing and alert systems**.



⚙️ Components Used
- Arduino UNO  
- Ultrasonic Sensor (HC-SR04)  
- Buzzer  
- LED  
- Jumper Wires  
- Breadboard  



🧩 Working Principle
1. The Arduino sends a pulse from the **Trig pin** of the ultrasonic sensor.  
2. The pulse bounces back and is received by the **Echo pin**.  
3. Arduino calculates the time taken and converts it to distance.  
4. If the object is too close, the **buzzer** and **LED** are activated.
